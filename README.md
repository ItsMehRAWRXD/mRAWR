### Option 1: Use MASM (Recommended)
1. Install MASM32 SDK from http://www.masm32.com/ OR Visual Studio with MASM support
2. Run: `build_masm.bat`
3. Get: `MASM_2035_Weaponized_Complete..exe`

### Option 2: Convert to NASM
The code would need to be converted from MASM to NASM syntax (major rewrite required). See `BUILD_INSTRUCTIONS.md` for details.
